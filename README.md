# Aiops self healing simulation

## Project Overview
This repository contains a software MVP prototype and a stochastic simulation model designed to automate IT infrastructure management for manufacturing environments (Industry 4.0). The system implements a **Self-Healing** paradigm using **AIOps** principles to minimize **MTTR** (Mean Time To Recovery).

## Key Features
* **Hybrid Incident Routing:** Automated separation of software glitches (machine loop) and hardware failures (human loop).
* **Self-Healing Engine:** Instant autonomous remediation of 80% of common software issues.
* **Stochastic Simulation:** 168-hour (7-day) operational cycle simulation with Poisson-based incident generation.
* **Statistical Analysis:** Built-in MTTR optimization tracking and reliability verification.

## Tech Stack
* **Language:** Python 3.10+
* **Modeling:** UML 2.5 (Architecture Design)
* **Data Processing:** Pandas, NumPy
* **Visualization:** Matplotlib
* **Simulation:** Discrete-event stochastic modeling

## Experimental Results
* **MTTR Reduction:** 64.63% (statistically significant at p < 0.001).
* **Reliability:** Minimal variance (σ = 3.2 min) compared to manual management (σ = 42.5 min).

## Project Structure
* `auto_simulation.py` — Core simulation script for the AIOps-based autonomous management loop.
* `manual_simulation.py` — Baseline simulation script representing traditional manual IT management.
* `compare_analytics.py` — Statistical analysis and comparison module (Pandas-based).
* `auto_results.csv` / `manual_results.csv` — Datasets generated by the simulation models.
* `auto_system.log` / `manual_system.log` — Telemetry and incident processing logs.
* `final_24_7_comparison.png` — Visual validation graph of the experimental results.
* `requirements.txt` — List of necessary Python dependencies.
